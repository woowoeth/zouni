# 04 · 流程和命令

在项目根目录执行。**容器里单条命令超过 300 秒会被掐断**，下面每一步分开跑，别串成一条。

## 改了数据以后

```bash
python3 tools/build_catalog.py build/catalog.js        # 目的地、列表
python3 tools/estimate_prices.py                       # 回填人均价
timeout 100 python3 tools/build_routes_js.py build/routes.js
timeout 150 python3 tools/compile_itineraries.py build/routes.js   # 排时间、算路程
python3 tools/gen_posters.py                           # 头图海报
timeout 60 python3 tools/price_parts.py
python3 tools/build_catalog.py build/catalog.js        # 再跑一次，带上新价格
python3 tools/validate_catalog.py build/routes.js > build/validate.txt   # 第一行必须是“错误 0”，并看“编号撞车 0”“住处矛盾 0”
```

再查一遍时间有没有过 24 点（排到半夜的线打开会被网页改时间）：
```bash
python3 - <<'PY'
import json,re
R=json.loads(re.search(r'window.ZOUNI_ROUTES=(.*);\n',open('build/routes.js',encoding='utf-8').read()).group(1))
print([f'{k} 第{i+1}天 {w["t"]}' for k,r in R.items() for i,d in enumerate(r['days']) for w in d['rows'] if re.match(r'^\d+:\d\d$',w.get('t') or '') and int(w['t'][:2])>=24])
PY
```

## 发布

```bash
sh tools/deploy_site.sh "这次改了什么"      # 推到 woowoeth/zouni main，并盯 Pages 构建
```
- 令牌在容器临时文件 `/tmp/.zt_read`、`/tmp/.zt_push`（不进仓库、不打印；新环境找 Jerry 要）
- **Pages 会抽风**：显示“errored → 请求重建”时，等一分钟后查 GitHub Actions 最新一次是否 success，再直接请求线上 `site.css` / `site.js` 看新内容在不在。连续失败别反复推空提交（会堵队列），等 GitHub 恢复或随下一次正常发布带上

## 数据和页面检查（2026-10 新增，改完数据必跑）

```bash
python3 tools/build_site.py /tmp/zsite
python3 tests/data_checks.py /tmp/zsite      # 不给站目录就只查数据；任一项不过退出码为 1，并打印具体的线和天
```
查的是：坐标隐含车速（作者写的去程时间和坐标算出的距离对不上）、城市中心离目的地基准点过远、站点离城市中心过远、缺城市中心键、南半球纬度符号、每页的 `data-n0`/`data-start`/天数、默认出发日晚于今天且不让“周一闭馆”落在周一、串线闸拒绝的文案不得出现在页面里。每一项都反向验证过（把已修的错误放回去会红）。

## 在 macOS 上跑（不是 Linux 容器）

- 没有 `timeout`，去掉即可；`base64` 没有 `-w0`
- **本机 Python 的 `urllib` 访问 HTTPS 会 `CERTIFICATE_VERIFY_FAILED`**：`compile_itineraries.py` 里在线地理编码会静默全失败，还会把失败缓存成 `None` + `#tried`（之后不再重试）。新线补坐标用 `curl` 查 Nominatim（`countrycodes=cn`，1.2 秒一个），**逐个核对命中位置**，不要关证书校验
- 发布：克隆 `woowoeth/zouni` 的 main（公开，不用令牌）→ 替换为新建的站（保留 `.git`/`.github`）→ `git diff --cached --name-status` 确认 0 个删除 → 提交 → 推送（令牌放环境变量 `GIT_CONFIG_COUNT=1 GIT_CONFIG_KEY_0=http.extraheader GIT_CONFIG_VALUE_0="Authorization: Basic …"`，不写文件）。线上手绘封面 `assets/blob/*.svg` 在 source 分支里，本机项目缺这个目录会让 19 个页的头图退化，发布前先和线上逐文件对比

## 首页“替我挑三条”的矩阵检查（在浏览器里跑）

`tests/home_matrix_browser.js`：打开首页（本地 `python3 -m http.server` 起建好的站），把整个文件贴进浏览器控制台（或 `page.evaluate`）。37 个出发城市 × 周末/4–5 天/一周以上 × 三种同行 × 自驾也行/不开车 = 666 组，每组读前三条，断言：每组 3 条（不足时有说明）、同省 ≤2 条、“不开车”不含自驾、“带老人孩子”不含高原（最高天标 ≥2,500 米）和国外、每个城市周末距离中位数 ≤600 公里、4–5 天 ≤900 公里、周末有 >450 公里的推荐时页面有说明。返回 `{组数, 失败: [...]}`，失败为空才算过。
这个检查是 2026-10 因为“注释吞掉了后面的分支”才补的：4–5 天、一周以上的筛选曾经整个失效而没人发现。
