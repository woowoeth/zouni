# 01 · 做了什么

## 网站结构

| 页面 | 地址 | 说明 |
|---|---|---|
| 本期（首页） | `/` | 杂志封面：刊名“走你”、刊期“2026 · 十月”、封面故事（当季推荐一条线）、出发日期 |
| 走哪儿 | `/where/` | 国内 / 亚洲 / 更远三个切换；按月份看“正好去 / 也行”；地图看、筛选；按分区（华北、华东…欧洲、北非、非洲、北美、拉美、大洋洲）列目的地卡 |

| 片子页 | `/shejian/` `/fengwei/` `/yuanchandi/` `/zaocan/` `/guobao/` `/xiangchou/` `/yichuan/` `/xiaoye/` `/hexi/` `/shuben/` `/hangpai/` | 每部片子拍过的地方或吃的；能去的直接链到排进去的那条线的那一天 |

## 行程页有什么（从上到下）

1. 头图（插画海报）、小字（城市 · N 天）、大标题
2. 三格：天数和日期（可改）、开不开车、人均价格（几人可改）
3. 怎么去、怎么回（按你选的出发地重算）
4. 出发前要办的事：要预约的门票、往返车票、**长线中途换城市的火车票 / 机票**（写哪天开售），能打勾、能加到手机日历
5. N 天，怎么排：每天一行，能点过去；住三个地方以上的线多一行“住：西安 2 晚 → 兰州 1 晚 → …”
6. 每一天：标题、出发和日落、往年气温、纪录片那一行、当天一句话、时间轴（出发 → 景点 → 吃饭 → 回住处，每行有时长、门票、一句话介绍，导航 / 点评 / 小红书图标）、“懂一点”（景点来历）
7. 每天下面“＋ 这天后面加一天”：可以在这里多留一天，或接 100 公里内别的线里的一天，插在这天后面，后面顺延（最底下还有一个“加一天”加在回程前）
8. 去掉这一天、改这天几点出发（后面自动顺延）
9. 住宿卡（推荐三档、携程订这家）
10. 常见问题（默认收起）、附近还能去
11. 底栏：出发日期 · 天数 · 每人价格、收进行程、按天看（一天一屏，左右滑换天，有“下一站”导航）

## 内容

- **线路**：国内 34 个省级都有，热门地方基本都有线；这一段集中补了：
  - 不开车的长线（坐高铁 / 火车）：丝绸之路、苏杭乌镇、湖南、云南、川渝、广东、福建、哈尔滨雪乡、山西古建、京津冀、海南环岛、广西、江西、贵州、新疆、黄山宏村、内蒙古、拉萨林芝、东北三省、湖北、江苏、山东、河南、宁夏、青海、浙东、渝东南、京杭大运河、长江三峡游轮等
  - 城市深度游：北京、上海、广州、重庆、成都、西安
  - 季节线：红叶、雪景、温泉、樱花、杏花、滑雪
  - 课本线（带娃）：北京、江南、桂林、西安、济南、岳阳
  - 国外 26 国：日韩东南亚南亚中亚西亚 22 国（亚洲），欧洲、北非、非洲、北美、拉美、大洋洲 26 国（更远）
- **景点一句话**：写在 `tools/build_site.py` 的 `SIGHT` 字典里；还没有介绍的约 160 个
- **懂一点**：写在 `DEEP` 字典（一处一段来历），一天最多补两处
- **纪录片**：舌尖上的中国、风味人间、风味原产地、早餐中国、如果国宝会说话、记住乡愁、人生一串、宵夜江湖、河西走廊、跟着书本去旅行、航拍中国（1–4 季，按省挂目的地页）、老广的味道（1–7 季，约 200 个“吃的@地点”）、话说长江（25 集里地点明确的 18 处）、新丝绸之路（中国篇 8 处）、中国影像方志（868 个县，一集一县，按省分组）；如果国宝会说话补到第二至四季；丝绸之路（1980，6 处）；旅行类：菲尔来蹭饭（8 季，33 座城）、未知之旅（安东尼·波登，12 季，约 40 处），只收站上有对应目的地的城市；杂志榜单：孤独星球 Best in Travel（2027、2026 年榜）、国家地理 Best of the World（2026 年榜），按年份分组，行程里写“入选 成都（2027 年榜）”，只收站上有的目的地
- **门票、酒店、坐标**：`data/catalog/tickets.json`、`data/hotels/ctrip_hotels.json`、`data/geo/pois.json`

## 关键决定（别轻易推翻）

- 频道名：“去哪儿”改叫**走哪儿**，“跟着纪录片去”改叫**跟片走**（贴“走你”的“走”；避开去哪儿网）
- 高德、大众点评、小红书、携程：**手机上只开 App**，不退回网页；电脑和微信里不放这些入口
- 每天末尾的“下一天”链接已删（Jerry 说多余，天数条一直在）
- 频道页暂时**不加图片**，只靠排版做杂志感（Jerry 明确说的）
- 纪录片只收**查得到出处**的那一期；查不到分集就只按“拍过这一段”挂到城市，不编
- 景点介绍不重复：时间轴里那句话，如果“懂一点”已经讲到这个景点，就不再显示
