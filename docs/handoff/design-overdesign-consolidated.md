## 1 · 用户已点名的整合（最高优先）
**一天的行程只留一份“当天模型”**（时间、站点、车程、吃饭、预约/闭馆、调整/去掉/撤销、路上/走路数字都从它读）：
- 整屏地图底部面板里的列表 = 页面上同一份当天行程（完整时间轴，不是简版站点表）。
- 页面、地图面板、按天看、导航、日历、复制行程都读同一个函数；任何一边改，另一边立刻同步。
- 联动：点行→地图飞到该站；点图上站点→行高亮；点车程行→高亮该段；页面本身不动。
- 入口合并：页面每天的“本日地图”和总览的“看路线图”进同一个整屏地图，面板里切天；不再有独立天标签与简版列表。
- “按天看”（.tv）保留为大字模式，但与面板同源渲染（先做 A：保持独立、三处同源；是否并进面板拉满另议）。

## 6 · 去冗余波（2026-10-19）：做了什么、没做什么、假设清单

做的内容和规则写在 `02-UI规范.md`“2026-10-19 去冗余波”；判据 `tests/wave2_check.py`（每项有 `--inject`）、`tests/title_check.py`；没做到的写在 `06-待办.md` 最后一节。**这一波的“用户决定”都按“少就是多 + 可回退”选了默认，登记如下，随时可否决：**

### 假设清单（每做一个没问用户的假设就登记）
1. **首屏控件只减到 12（旧 14），不是“约 10”**：频道四格数量不动（用户要求），再减要动向导 / 日期 / 天数键。
2. **向导里的“几天”没删，改成和“现在去正好”的天数键同一个状态**（避免动 666 组矩阵测试）；向导只持久化“和谁去、出行方式”，天数跟着页面上那排键走（刷新后向导里的天数是空的）。
3. **搜索框的“搜”按钮删了**（回车 / 手机的“搜索”键；打字时下拉里有“搜全部「xx」›”一行兜底）。
4. **天数键没有“全部”**：再点一次选中的就取消；向导里点已选项也取消（出发地除外）。
5. **出发地全站一个键 `zouni_org`，城市表只有 `site.js` 的 `ZORIG`**：/where/ 的下拉从 11 个城市变成 37 个；南宁坐标按 JS 表（108.32）改了 Python 里的 108.37；老的 `zouni_pick.o` 第一次打开时迁移过去。
6. **日期全站一个键 `zouni_date`，没做“每线覆盖”**；朋友分享链接里的日期会改我的全站日期（撤销条“换回我自己的”能还原）；老键取时间戳最新的一个迁移。
7. **人数全站一个键 `zouni_n`**：线路页步进器改它，首页“和谁去”只在选的时候写默认（取消不改人数）。
8. **/where/ 搜索框有字时，不再用“只看合适的”过滤**（按钮保持亮着，清空搜索即恢复）。
9. **线路按 `group_city` 归组**：≥ 8 条且 ≥ 2 组才分；没有 `group_city` 的 7 条新线落在“其他”；“主推哪一条”按补丁里的 `main`，页面上没有再标“主推”。
10. **姐妹线互链放在“N 天，怎么排”下面一行**（不放进“附近还能去”：那个按距离排，同城永远出不来）；只对 `sisters.ids` 里的行程出现，167 条。
11. **被覆盖线只做 canonical，页面保留，不 301、不从列表和 sitemap 里去掉**（没有统计，没法证明没人用）；补丁里 `apply=false` 的 14 条不写。
12. **影视挂钩收成一个折叠放在“看 / 吃”后面**（不放进“吃”），折叠里还是一部片一段。
13. **默认值标签**：5A 不标只标世界遗产；红框“国宝”整个删（“镇馆之宝”那行已说）；小众“可以去”不标；主题页 / /long/ 卡片“平路”“N 月出发”删。
14. **跟片走**：每条片子条目的主链接取排进行程最早的那条；中国影像方志省份折叠默认全部收起（点上面的省名展开）；纯地名“中国影像方志拍过 X”只对这一档隐藏，“记住乡愁”的村子名这类保留。
15. **toast**：只留带撤销的、出错 / 限制类的、第一次才说的；“链接已复制 / 行程已复制”留着（剪贴板没有别的反馈）；没有按钮的提示时长按字数（1.7–6 秒）；微信提示改成第一次点“复制”时再说（记在 localStorage，每台设备一次）。
16. **“出发 → 住处 / 打车或步行”直接不渲染**（DOM 里就没有这一行，不是隐藏）；“回去歇一下”“沿途慢慢走”“没有酒店名的住宿卡”只折样式，DOM 不变（JS 读它们）。
17. **复述标题的导语**：判据“去掉站名 / 标题 / 城市 / 上午下午去看之后 ≤ 6 个字”，约 29% 的天；带 `hidden` 留在 DOM 里（复制行程、改标题的 JS 还读它）。
18. **高反**：第一次到这个高度（≥3000 / ≥2500 各算一次）写全，之后每晚一行；≥3500 米带醒目样式；安全内容没删，只压缩重复。
19. **“人物：”前缀**只在整页第一条站点注释写。
20. **价格写法** `¥2600–3600/人`：取整到百元、不写千分位、“人均”两个字去掉（单位在后面）；/where/ 预算下拉也不再写 K。

22. **a11y #8（分布图按钮嵌链接）**：去掉 `role=button` / `tabindex`，点图放大保留给鼠标 / 触屏，键盘用户的放大靠“看地图”；没加独立“放大”按钮（少一个控件）。

24. **输入类**：#4 存不下只改 toast，没做内存兜底；#8 点击区上一轮已用 `:after` 撑到 44，没再加。
25. **新增一条构建期会红的判据**：行程标题不得以“N天(…)”开头、同一目的地 label 不重名（`tests/title_check.py`，`tools/validate_catalog.py` 也调它，pipe.sh 第二行“错误 N”会带出来）。
