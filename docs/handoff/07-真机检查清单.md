# 真机检查清单（上线前后各走一遍）

自动化测试都是电脑浏览器（Chromium）里跑的，下面这些只有真机才能确认。每项写“通过/不通过/备注”，不通过的截图发回来。

## 设备与环境
- iPhone Safari（至少一台，最好 iOS 16 以上）
- 微信内置浏览器（iOS 和 Android 各一台）
- Android Chrome
- 网络：Wi-Fi、4G/5G、弱网（电梯里或开飞行模式后再开 Wi-Fi）、完全断网

## 1 首页和找线路
1. 首页第一屏能同时看到搜索框和“走哪儿 / 跟片走 / 跟谁走 / 长线自驾”四格，不用滚动。
2. 搜“苏轼”“长征”“105 天”，第一条是不是人物或线路，能一下点进去。
3. “长线自驾”页里选月份和天数，筛选结果对，返回后条件还在。

## 2 线路页和调整
4. 打开 /trip/xa3/，每天标题下有“走路约…开车约…”，和页头“不开车/开车”一致。
5. 点“调整”→“在这之后加一个”，候选出现，选一个后时间表重算，点“撤销”回到原样。
6. 改出发日期到周一，页面顶部出现闭馆提醒，改回后消失。

## 3 地图（最重要；2026-10-18 起是“地图 App 式”整屏界面）
7. 点“看路线图”：**马上**（不到半秒）出现整屏的示意图 + 线路 + 半屏面板，顶上有细进度条和“街道地图加载中…”；几秒内街道底图淡入盖住示意图，不闪白。没出来时是否退回示意图，并有“重试”。
8. 单指拖动、双指缩放（以两指中心）、双击放大、双指轻点缩小、惯性滑动：**页面本身不应滚动也不应缩放**（手指起点落在站点方块上也一样；iPhone 要试双指捏合和地址栏有没有被拉动）。双指旋转默认不转。
9. 右侧“回到视野 / + / −”、右上“存图”、右下“i”都点得到、够大，没有被面板或浏览器栏遮挡；iPhone 看底部安全区（面板底、i 有没有被横条盖住）。
10. 底部面板：上下拖会吸附到三档（收起只露一条 / 半屏 / 拉满），有惯性；拉满后列表自己滚，**滚到顶继续下拉才收起**；半屏时地图露出一半以上。手指在面板上拖的时候页面和地图不应跟着动。
11. 左上“×”能关，手机返回键也能关；关闭后回到原来的位置（在地图里选过某一站，关闭后页面滚到那一行并高亮）。iPhone 要看返回键 / 边缘右滑返回会不会直接离开页面、而不是先关地图。
12. 点地图上的站点：地图平滑飞过去，面板换成该站卡片（名字、一句话、预约 / 闭馆、距上一站 / 下一站）；卡片左右滑切换站点、地图跟着飞；点空白处回到列表；点列表某行同理。灰点（顺路可去）点开有“+N 分钟”和“加到这天”，加完能“撤销”。
13. “导航这一天”（面板底部唯一的墨色大按钮）：国内线打开高德，会分几段；点第一段能唤起高德 App；国外线打开谷歌地图。微信里如果不能唤起，要有可复制的链接。导航分段层打开时按返回键：先关分段层、地图还在。
14. “存图”：保存的图片清楚，有二维码，二维码能扫出线路网址，只存面板上方露出来的那一块。
15. 断网：地图直接是示意图并写“没有网络，已改用示意图”，“导航这一天”置灰并写明原因；联网后自动重试；已收进行程的线路仍能打开。
15a. 暗色模式：地图底图反色、线和方块颜色换成暗色版、面板是暗色，没有刺眼的白块。
15b. 中文地名：地图上的中文标注显示正常（不是方块）——安卓机没装中文字体时可能退成方块，记下机型。

## 4 跟谁走
16. 首页进“跟谁走”，两次点击内到苏轼；类别快捷入口能点，选中项始终看得到。
17. 主题页年表日期不折行，字大小够读；线路页每站“苏轼：……”读起来平实，没有夸张的话。
18. 抗战、红色类线路页：没有订房点评、没有美食影视标签；参观礼仪在“出发前”第一条；下雨备选里没有纪念馆。
19. 博物馆闭馆提醒：只在会撞上闭馆日的天出现，不是每个馆都挂同一句。

## 5 速度和稳定
20. 首次打开首页到能点开日历要多久（弱网下记秒数）。
21. 连续点开三个不同线路的地图，页面不卡死、不白屏；退出后内存不涨到浏览器崩溃。
22. 国内网络下，地图瓦片是不是明显慢；记下“点开到出现示意图”（应该瞬间）和“点开到街道图出现”的秒数（第一次和第二次各一次；第二次应该明显更快）。

## 6 弹层与返回键（2026-10-18 层栈；Chromium 里实测过，真机只有这几条能确认）
23. 每个弹层（分享、选日期、几点出发、加一天、改这一站、调整这一天、复制框、我的行程）：右上只有一个“×”（够大、不被刘海 / 灵动岛遮住），顶上有一条小横条；**手机返回键 / iOS 边缘右滑只关最上面一层**，页面滚动位置不变；再按一次才离开页面。
24. **向下滑动关层**：从标题行或小横条往下拉 ≥ 100px 关；短拉松手弹回；内容很长（“我的行程”收了很多条）时，内容滚在中间往下拉**只滚内容、不关层**，滚到顶再拉才关；拉的时候页面背景不跟着动，iPhone Safari 不出现回弹 / 下拉刷新。
25. **叠加**：地图 → “导航这一天”分段层 / “存图” / 点站点卡片里的“调整这一站”，返回键只关最上面一层，地图还在、背景仍锁住；再按一次才关地图并回到原位置。
26. **分享图（存图层）**：返回键、点图片以外、右上 × 都能关（原来返回键不响应，会直接离开线路页）；长按图片能保存。
27. “去掉这一天”：每天底部一个“调整这一天 ›”，层里点“去掉这一天”**直接执行**，页面重载后底部提示条 5 秒内有“撤销”；点撤销天数回来。（页面重载后滚动位置可能不在原来那天，记下来。）
28. 底栏的日期价格（滚过页头才出现）点一下打开日期选择；日期条（1 2 3）往下滚收起、往上滚露出——微信 X5 内核里应一直常驻，记下有没有收起。
29. 当天末尾“晚上 住 · …”一点跳到这一晚的住宿卡（卡顶不被吸顶日期条盖住）；长线页头“住：… → …”每段可点。
